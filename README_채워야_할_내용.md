## 참석 여부 전달 (2026-09-06 추가 · 2026-09-20 구글 시트 연결)
- 웹 앱이 403(액세스 거부됨)을 돌려주면: 배포 관리에서 액세스 「모든 사용자」 + 버전 「새 버전」으로 다시 배포하고 권한 승인(Advanced → Go to … → Continue)을 끝까지 마쳤는지 확인. 코드 수정 후에도 「새 버전」 배포가 필요하다.
- 첫 진입 6초 뒤 팝업(신랑·신부 / 일시 / 장소 + 「오늘하루 보지않기」) → 「참석 여부 전달」 버튼 → 전체 화면 입력창.
- 입력 항목: 신랑/신부 측 · 참석/불참석 · 식사 ○/✕/미정 · 성함 · 동행 인원(본인 제외, 없음~5명 선택) · 전달사항 · 개인정보 동의. (2026-09-20 「동행인 성함」을 「동행 인원」으로 변경. 숫자로 전송되어 시트 「집계」 탭이 참석·식사 인원을 본인+동행으로 합산)
- 전달 방식은 `index.html` script 상단 두 상수로 정한다.
  - `RSVP_ENDPOINT`가 비어 있으면(기본): 하객 폰의 **문자 앱**이 열리고 `RSVP_SMS` 번호로 답변이 자동 입력된다. 하객이 전송만 누르면 된다.
  - 구글 시트에 모으고 싶으면: 구글 시트 → 확장 프로그램 → Apps Script에 `doPost(e){ var d=JSON.parse(e.postData.contents); SpreadsheetApp.getActiveSheet().appendRow([d.at,d.kind,d.attend,d.meal,d.name,d.people,d.memo]); return ContentService.createTextOutput('ok'); }` 저장 → 「배포 > 웹 앱, 액세스: 모든 사용자」 → 나온 URL을 `RSVP_ENDPOINT`에 넣는다. 해피에게 요청하면 대신 안내 가능.
